2. الملفات التي تعدل منها بياناتك الشخصية
--------------------------------------------------------------------------------
جميع البيانات الشخصية مجمعة في ملف واحد لسهولة الصيانة:

 الملف: data/cv-data.js
 - الاسم الكامل (العربية/الإنجليزية)
 - المسمى الوظيفي
 - الموقع، البريد، الهاتف، روابط LinkedIn/GitHub/معرض الأعمال
 - نبذة تعريفية (summary)
 -兴趣ات، الأهداف، نقاط القوة
 - المهارات (تقنية، برمجة، أدوات، شخصية، لغات) - دون مبالغة في النسب
 - التعليم (الجامعة، التخصص، الدرجة، التواريخ، الدورات)
 - المشاريع (أضف مشاريع جديدة بم hetzelfde الهيكل)
 - الخبرات العملية (مصفوفة فارغة افتراضياً - لا تُخترع خبرات)
 - الشهادات والإنجازات (مصفوفة فارغة افتراضياً)

 после التعديل في cv-data.js، ينعكس التغيير تلقائياً على:
 - الموقع الإلكتروني (index.html)
 - صفحة PDF العربية (cv-pdf.html) عبر CSS طباعة منفصل
 - صفحة PDF الإنجليزية (cv-pdf-en.html)

ملاحظة: بيانات الناقصة تم تمييزها ك.placeholders للتعديل لاحقاً (مثل بريدك وهاتفك ورابط صورتك).

3. طريقة تشغيل الموقع محلياً
--------------------------------------------------------------------------------
الخيار أ: فتح الملف مباشرة (الأبسط)
  1. افتح مجلد my-cv في مستكشف الملفات.
  2. انقر نقراً مزدوجاً على ملف index.html لفتحه في المتصفح.

الخيار ب: استخدام خادم محلي (مفضل للتطوير وتجنب مشاكل CORS مع ملفات الترجمة)
  باستخدام بايثون (إذا كان مثبتاً):
    $ cd C:\Users\manso\Desktop\my-cv
    $ python -m http.server 8000
    ثم افتح في المتصفح: http://localhost:8000

  باستخدام Node.js (إذا كان مثبتاً):
    $ npx serve .
    ثم افتح الرابط الذي يعرضه الأمر.

ملاحظة: ملفات الترجمة (ar.json, en.json) تُحمل عبر fetch، لذا قد لا تعمل
في بعض المتصفحات عند فتح ملف HTML مباشرة (file://). استخدم خادم محلي لضمان عملها.

4. ميزات الموقع المنفذة
--------------------------------------------------------------------------------
✅ دعم اللغتين العربية والإنجليزية كاملاً (i18n مركزي في ملفات JSON)
✅ العربية افتراضية مع اتجاه RTL، الإنجليزية LTR
✅ زر تبديل भाषा فوري (AR/EN) دون إعادة تحميل الصفحة
✅ حفظ اختيار اللغة في Local Storage (يتذكر اختيار الزائر)
✅ خصائص CSS منطقية (Logical Properties) لدعم RTL/LTR تلقائياً
✅ وضع داكن وفاتح (Dark / Light Mode) مع حفظ التفضيل
✅ تصميم متجاوب بالكامل (جوال، تابلت، كمبيوتر) مع تجربة جوال ممتازة
✅ جميع الأقسام المطلوبة: الرئيسية، عني، المهارات، التعليم، المشاريع، الخبرات، الشهادات، التواصل
✅ مكونات مستقلة لكل قسم (قابلة لإعادة الاستخدام)
✅ بيانات مركزية منفصلة عن التصميم (ملف cv-data.js واحد)
✅ أنيميشن ناعمة وتأثيرات تفاعلية عند التمرير
✅ أيقونات عصرية وألوان احترافية متجانسة
✅ تحسين محركات البحث (SEO) مع بيانات Open Graph و Twitter Card
✅ إمكانية الوصول (Accessibility) مع aria-label وهيكل دلالي
✅ نموذج تواصل يعمل عبر برنامج البريد الافتراضي (mailto)
✅ أزرار تواصل معي وتحميل السيرة الذاتية PDF
✅ صفحة PDF ATS-friendly مستقلة عن تصميم الموقع (عربية + إنجليزية، A4، عمود واحد، لا صور/أيقونات/رسوم بيانية)
✅ لا قاعدة بيانات ولا نظام تسجيل دخول (موقع شخصي ثابت)

7. اختبار PDF ATS-friendly
--------------------------------------------------------------------------------
لإنشاء ملف PDF من السيرة الذاتية:
  1. افتح cv-pdf.html (للنسخة العربية) أو cv-pdf-en.html (للإنجليزية) في المتصفح.
  2. اضغط Ctrl+P (أو Cmd+P على ماك) لفتح نافذة الطباعة.
  3. اختر الطابعة "Save as PDF" أو "Microsoft Print to PDF".
  4. تأكد من أن حجم الورقة مضبوط على A4 والهوامش طبيعية.
  5. اضغط "حفظ" أو "Print".

ملاحظات ATS:
- النص قابل للتحديد والنسخ بالكامل (ليس صوراً).
- تخطيط عمود واحد (Single Column) دون جداول أو أعمدة متعددة.
- عناوين أقسام تقليدية: Professional Summary, Education, Skills, Projects, Certifications.
- لا استخدام لصور أو أيقونات أو رسوم بيانية لتقييم المهارات.
- يمكن استخراج النصوص آلياً بواسطة أنظمة تتبع المتقدمين.

8. النشر على الإنترنت (Staging / Production)
--------------------------------------------------------------------------------
بما أن الموقع ثابت (Static HTML/CSS/JS)، يمكن نشره مجاناً على:

أ) GitHub Pages (مجاني ومRecommend):
   1. ارفع جميع الملفات إلى مستودع (Repository) على GitHub.
   2. اذهب إلى Settings > Pages > اختر الفرع (main/master) والمجلد الجذر (/root).
   3. سيصبح الموقع متاحاً على: https://username.github.io/repo-name/

ب) Vercel أو Netlify (مجاني وسريع):
   1. اربط مستودع GitHub أو ارفع المجلد directamente.
   2. سيُنشأ الموقع تلقائياً مع نطاق مخصص مجاني.

ج) أي استضافة ويب تقليدية تدعم ملفات HTML ثابتة.

قبل النشر:
 - استبدل 모든 placeholders في data/cv-data.js ببياناتك الحقيقية.
 - أضف صورتك الشخصية الفعلية في assets/images/profile.jpg.
 - أضف صورة og-image.jpg للمشاركة على وسائل التواصل.
 - استبدل الرمز # في روابط المشاريع ووسائل التواصل بروابطك الحقيقية.
 - اختبر الموقع على متصفحات مختلفة (Chrome, Firefox, Safari, Edge) وأحجام شاشات متعددة.

9. اختبار الجودة (QA) قبل النشر
--------------------------------------------------------------------------------
- [ ] افتح الموقع على جوال، تابلت، وكمبيوتر وتحقق من الظهور الجيد.
- [ ] افتتح وضع داكن وفاتح وتحقق من عدم كسر أي عنصر.
- [ ] غير اللغة من AR إلى EN وتحقق من تغيير اتجاه الموقع والنصوص.
- [ ] إغلاق وإعادة فتح المتصفح وتذكر اللغة والوضع المفضلين.
- [ ] اضغط على جميع الروابط والأزرار وتأكد من عملها.
- [ ] افتح Console (F12) وتأكد من عدم وجود أخطاء.
- [ ] افتح cv-pdf.html واطبعه كـ PDF على A4 وتحقق من عدم وجود صفحات فارغة أو قطع نص.
- [ ] تحقق من استخراج النصوص من PDF (نسخ ولصق في محرر نصوص).

10. تحديث البيانات مستقبلاً
--------------------------------------------------------------------------------
1. افتح ملف data/cv-data.js.
2. عدل البيانات التي تريد (مشاريع جديدة، خبرات، شهادات، مهارات، إلخ).
3. احفظ الملف وافتح الموقع مرة أخرى - التغييرات تظهر فوراً.
4. للنسخة PDF، افتح cv-pdf.html أو cv-pdf-en.html واطبعها من المتصفح.

لا حاجة لتعديل أي ملف CSS أو HTML لإضافة مشروع أو خبرة جديدة - كل شيء من cv-data.js.
